#Movie Watchlist
##GitHub Repository:
https://github.com/sr928400/movie-watchlist.git
###This website allows users to create and manage a movie watchlist.  Each movie is stored as an object with a title, genre, and watched status.  The watchlist object contains a toggleWatched() method that changes a movie between watched or not watched and removeMovie() method that removes a movie from the list.  Movie list is saved using localStorage, JSON.stringify() saves the movie array, and JSON.parse() is used to load it when the page is reopened.
